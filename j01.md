# Building Songs by Building Patterns in FL Studio #

FL Studio is one of the most widely used digital audio workstations available today. A digital audio workstation is software that allows users to digitally
compose music using various input sources like instruments connected to an audio interface connected to the computer or digital plugin software that utilizes
a computer's audio card to generate digital sounds. These digital audio workstations come outfitted with a large amount of settings to allow the user to have
a large level of control over the final product.

FL Studio stands out from other workstations in that the users creates full length songs by layering and stringing together smaller segments called patterns. 
However, this process can be complicated due to the design of the application. 
Let's say that I task myself with creating a simple drum beat that infinitely loops. 

Upon opening FL Studios, I am greeted with this page.

<img width="800" height="400" alt="Screenshot (107)" src="https://github.com/user-attachments/assets/ba1f7f84-4afa-4517-a405-323c8adef437" />

For programming a simple drum beat, it is clear to me that I need to configure the channel rack in some way because it has instrument names on each row and 
the columns of the channel rack appear to be switches for toggling a hit on the instrument at a particular time. These switches are naturally mapped to 
what are called sixteenth notes of a measure. Since there are sixteen switches for each of these instruments, these sets of switches make up a conceptual
model of musical measures which match my mental model.

I flip some switches in an arrangement that I believe to be a rhythm I am seeking to create.

<img width="800" height="400" alt="Screenshot (108)" src="https://github.com/user-attachments/assets/e79479ef-bdb9-435b-a113-1f0829670414" />

I want to hear the rhythm that I have configured so I hit the play button at the top. The rhythm I configured plays and I can hear the audio. It's exactly what I 
would expect. Since I've just created one musical measure, I'll now set out to have this measure play twice and then play a completely different configuration
twice. This is where it gets tricky.

Clearly I know that I have configured a measure, but I have recieved no feedback from the application that I have created a pattern. However, that is exactly 
have done. By configuring the channel rack, the user is in fact configuring a pattern. Also, there is in fact some feedback the application provides, but
it is very subtle. 

<img width="339" height="280" alt="image" src="https://github.com/user-attachments/assets/95c7e6f0-ee9b-40e0-a027-c7007a0e811e" />

Within the pattern dock on the left, some dots are clearly visible under the button called Pattern 1. This means that pattern 1 has a configured channel rack.
In order to have this pattern repeat twice before playing a new pattern we need to utilize the playlist arranger which is the window behind the channel rack. 
It is not abundantly clear to new users what the playlist arranger window is used for. Initially I had to do a lot of guesswork to figure out that I needed
to drag and drop patterns into the playlist arranger. 

<img width="800" height="400" alt="Screenshot (109)" src="https://github.com/user-attachments/assets/63b7fed7-5a41-413f-9703-fb462444e422" />

Another thing that new users will be lost on is the song/pattern switch next to the play button at the top of the screen. If the switch is set to pattern, 
only the currently selected pattern will play. If the switch is set to song, then what is in the playlist arranger will play. Those with experience using
digital audio workstations would most likely find this to be confusing. With the switch set to song, I hit the play button and the first pattern I created
plays twice as intended.

<img width="505" height="399" alt="image" src="https://github.com/user-attachments/assets/0ac1827c-d828-4114-9c0c-f790712e6ef3" />

Now I need to create my second pattern to place after pattern 1. This is another difficulty for new users. How do I create a new pattern? At the top of the
screen where it says pattern 1, this is actually the selector for the current pattern. I think many users would be confused by the fact that the pattern
selector isn't very close to the pattern dock. 

<img width="401" height="209" alt="image" src="https://github.com/user-attachments/assets/d43a1512-d88a-4a58-9bde-cedd84f5b961" />

I hit the plus sign next to pattern 1 which creates a brand new blank pattern, pattern 2. I navigate back to the channel rack and configure it to how I'd like
pattern 2 to be and then I drag pattern 2 from the dock to append it to pattern 1 within the playlist arranger. I hit the play button at the top and the two
patterns play one after the other in a loop which was the goal.
